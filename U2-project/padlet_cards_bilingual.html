🧩 项目背景 · Context

用 Python 构建了一个有情绪的 AI 婴儿生命体模拟器

Built a Python-based AI life simulator with genuine emotional dynamics

  • 核心模型：CfC（闭合连续时间神经网络），64 神经元，5 维情绪空间
  • Core model: CfC neural network, 64 neurons, 5-dimensional emotion space
  • 情绪维度：效价 / 唤醒 / 安全感 / 连接感 / 探索欲
  • Emotion dims: Valence / Arousal / Safety / Connection / Seeking
  • 理论基础：Barrett 具身情绪预测、Porges 多迷走神经理论、Bowlby 依恋理论
  • Theory base: Barrett predictive emotion, Polyvagal theory, Bowlby attachment
⚙️ Phase 2 实现 · Phase 2 Implementation

为婴儿添加了三套生理调节系统

Added three physiological regulation systems to the infant agent

  • 昼夜节律振荡器（Clark & Watson 1989）：24 小时正性情绪 / 唤醒节律，随发育逐渐成熟
  • Circadian Oscillator: 24-hr PA/arousal rhythm, matures with development
  • 身体预算系统（Barrett 2017）：能量、水分、体温三维度，缺口直接影响情绪目标
  • Body Budget System: Energy / hydration / thermal — deficits modulate emotion targets
  • 自主神经控制器（Porges 多迷走神经）：背侧迷走（冻结）→ 交感（应激）→ 腹侧迷走（安全）三区域层级
  • Autonomic Controller: Dorsal vagal (freeze) → Sympathetic (fight-flight) → Ventral vagal (safe)

🔴 问题诊断 · Diagnosis

训练到 44.8% 发育进度时，从日志数据发现三个严重 bug

At 44.8% dev progress, log analysis revealed three critical bugs

  • Bug 1：唤醒维度冻结 σ=0.00，永远 73.1，零波动 → 交感激活乘法门控把所有底层方差归一成一个固定点
  • Bug 1 – Arousal frozen: Always 73.1, zero variance — sympathetic gating multiplied all variance to a fixed point
  • Bug 2：体温永久地板 thermal=0.1（最低值），睡眠恢复量（0.00015/帧）远小于消耗（0.001/帧）
  • Bug 2 – Thermal floor: Sleep recovery (0.00015/frame) far below drain (0.001/frame) — never recovers
  • Bug 3：分离疏离永久锁死 86.2% 时间处于 sep_phase=3（疏离），no_social_count 最高累计到 5011 帧无法重置
  • Bug 3 – Permanent detachment: 86.2% in sep_phase=3, no_social_count reached 5011 with no recovery mechanism
✅ Bug 修复 · Bug Fixes

三处精确修改，恢复情绪系统的动态活性

Three targeted fixes to restore emotional system vitality

  • 修 Bug 1：交感门控 aro_t × 1.2 + 10 → aro_t + 20（乘法→加法），底层方差得以保留
  • Fix 1: Sympathetic gating changed from multiplicative to additive, preserving underlying variance
  • 修 Bug 2：睡眠改为固定恢复 +0.003/帧、睡眠期间暂停消耗、温度感知范围 33-37°C 扩宽到 31-38°C
  • Fix 2: Sleep thermal recovery fixed-rate (+0.003/frame), drain suspended while sleeping, sensing range widened
  • 修 Bug 3：新增弱社交信号（0.05–0.3）渐进衰减 no_social_count；计数上限 cap 到 400 防无限累积
  • Fix 3: Added gradual decay on weak social signal; capped no_social_count at 400 to allow recovery

🧠 Phase 3 设计 · Phase 3 Design

社会共鸣系统 — 对应婴儿 3–6 月龄发育跃迁（dev ≥ 50%）

SocialResonanceSystem — maps to 3–6 month infant development milestone

  • 理论依据：Stern（1985）情感调谐理论
  • Theory: Stern's affect attunement (1985)
  • 情感调谐缓冲区：照顾者接触积累 → 效价恢复窗口打开（不再永远负值）
  • Attunement buffer: Caregiver contact accumulates → opens valence recovery window
  • 迷走神经成熟：降低腹侧迷走激活阈值 → 更容易进入"安全"自主区域
  • Vagal maturation: Lowers ventral vagal threshold → easier access to safe autonomic state
  • 社会性微笑萌芽：高质量接触 + 调谐积累 → 触发 +35 效价爆发，~4 分钟冷却
  • Social smile: Quality contact + attunement → +35 valence burst, ~4-min cooldown
🧠 Phase 4 设计 · Phase 4 Design

原始意向性系统 — 对应婴儿 6–9 月龄发育跃迁（dev ≥ 70%）

ProtoIntentionalitySystem — maps to 6–9 month infant development milestone

  • 理论依据：Tomasello（1995）联合注意理论 + Piaget 客体永恒性
  • Theory: Tomasello's joint attention (1995) + Piaget's object permanence
  • 期望记忆：对照顾者行为模式做慢速 EMA 学习，形成预期
  • Expectation memory: Slow EMA learning of caregiver patterns, forming predictions
  • 违反预期：模式偏差 → 唤醒 + 探索欲双峰共振（好奇/警觉）
  • Violation of expectation: Pattern mismatch → dual spike in arousal + seeking (curiosity/alertness)
  • 分离个体化：单独时探索欲不再归零，获得基础保底值
  • Individuation: Exploring alone no longer collapses — gains a minimum floor value
⏰ 自动化注入 · Automated Injection

创建定时任务：每 30 分钟检测发育进度，阈值达到时自动向 life_v2.py 注入代码

Created a scheduled task: checks dev progress every 30 min, auto-injects Phase 3/4 code at thresholds

  • 标记注释系统：在 life_v2.py 类定义区、main() 初始化区、主循环区各埋入 BEGIN/END 标记，训练时不影响运行
  • Marker system: BEGIN/END comment anchors in class section, init, and main loop — invisible during training
  • phase_status.json：记录哪些阶段已注入，保证幂等性（不重复注入）
  • State file: Tracks which phases are applied — idempotent, won't inject twice
  • 注入后：任务提示用户重启 life_v2.py，新系统立即激活
  • After injection: Task prompts user to restart life_v2.py — new system activates immediately
